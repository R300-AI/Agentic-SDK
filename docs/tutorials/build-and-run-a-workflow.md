# 做出一條可以跑的工作流程

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/R300-AI/Agentic-SDK/blob/main/notebooks/01-build-and-run-a-workflow.ipynb)

這份教材帶你從一個小需求開始，組出一條可以執行的工作流程，送出使用者問題，取得回覆，並確認結果裡有哪些可供後續開發使用的資料。

## 你會學到

- 建立一條最小但完整的工作流程。
- 送出第一個問題並取得回覆。
- 分辨最後回覆與中間資料的差別。
- 知道接下來要看哪裡來追蹤執行過程。
