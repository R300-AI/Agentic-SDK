# 跑出第一條 Agentic SDK Workflow

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/R300-AI/Agentic-SDK/blob/main/notebooks/00-getting-started.ipynb)

這是教材共同的起點：安裝 SDK、確認 import 成功，並以 `PassThroughPerceive`、`KeywordRetrieve` 與 `DirectAnswerAction` 跑出一個可驗證的最小結果。

## 你會學到

- 安裝或更新 Agentic SDK。
- 確認目前環境載入的是預期的套件。
- 建立不需外部模型金鑰的最小 workflow。
- 從 `result.final_message` 取得最終回答。

完成後再繼續 [建立可組裝 workflow](build-and-run-a-workflow.md)。
