# 讓 Agent 接得住前後文

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/R300-AI/Agentic-SDK/blob/main/notebooks/03-multi-turn-conversation.ipynb)

這份教材示範如何用同一個對話識別碼連續跑多輪，讓 Agent 記得前面聊過的內容，而不是每次都從零開始。

## 你會學到

- 用同一個對話識別碼承接多輪對話。
- 觀察使用者與 Agent 的對話紀錄如何累積。
- 分清楚本輪狀態與前後文記憶。
- 知道什麼時候需要換記憶類型。
