# 讓 Agent 判斷什麼時候要叫工具

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/R300-AI/Agentic-SDK/blob/main/notebooks/05-call-tools-from-a-workflow.ipynb)

這份教材示範如何讓 Agent 產生工具呼叫，並由應用層接手執行。SDK 負責判斷要不要叫工具與整理參數；真正做事的部分由你的程式負責。

## 你會學到

- 定義一個工具可以接收哪些欄位。
- 讓 Agent 根據使用者需求產生工具呼叫。
- 檢查工具參數是否合理。
- 在應用層執行工具，再決定要如何回覆使用者。
