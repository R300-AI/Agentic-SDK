# 讓 Agent 先查資料再回答

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/R300-AI/Agentic-SDK/blob/main/notebooks/04-search-documents-and-answer.ipynb)

這份教材示範如何準備參考文件，讓 Agent 先查資料，再根據查到的內容回答。重點不是背參數，而是看懂資料怎麼被放進流程、怎麼被查回來。

## 你會學到

- 準備一批可查詢的參考資料。
- 讓工作流程先取回相關內容再回答。
- 觀察查回來的內容如何影響最後回覆。
- 理解重新打開 Agent 時為什麼需要保存參考資料與索引。
