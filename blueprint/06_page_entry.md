# Page Spec: Entry

## 頁面目標

入口頁只處理兩件事：

1. 使用者選擇匿名使用或登入 AI Hub
2. 將手動進站者導向正確模式

它不負責展示 Workflow、模組設定、程式碼或試跑功能。

## 可見條件

只有手動進站的使用者會看到入口頁。

若系統偵測到合法 AI Hub deep link，必須直接略過入口頁。

## Layout

### 整體風格

風格參考 Chrome 帳號選擇頁：

1. 整頁置中單一主卡
2. 乾淨留白
3. 視覺焦點集中在身份選擇
4. 不顯示工程化名詞

### 版面區域

1. 頂部品牌區
   - Agentic SDK Playground V2
   - 一句產品說明
2. 主卡片區
   - 登入 AI Hub 卡片
   - 匿名使用卡片
3. 底部輔助說明
   - Powered by Agentic SDK
   - 隱私/模式差異簡述

## 主要元件

### 品牌標題

顯示：

1. 產品名稱
2. 一句說明，例如：
   - 以 Agentic SDK Python Workflow 建立、試跑與保存你的 Agent 體驗

### 登入卡片

內容：

1. 帳號欄位
2. 密碼欄位
3. 登入按鈕
4. 說明文案：
   - 登入後可保存與更新你的 Workflow

### 匿名卡片

內容：

1. 匿名開始按鈕
2. 說明文案：
   - 不保存到 AI Hub，適合快速建立與試跑

## 互動規則

### 匿名使用

點擊後直接導到建構頁，模式為 `anonymous`。

### 登入使用

1. 呼叫 AI Hub 帳密驗證 API
2. 成功則建立 host-side session
3. 導到建構頁
4. 失敗則顯示卡片內錯誤提示

## 視覺效果

1. 登入卡與匿名卡應有明確 hover 狀態
2. 主卡區可使用柔和光暈或陰影，但不能像工程後台
3. 錯誤提示使用卡片內聯樣式，不使用瀏覽器 `alert`

## Loading / Empty / Error 狀態

### Loading

登入送出後：

1. 鎖定表單
2. 按鈕顯示處理中狀態
3. 禁止重複提交

### Error

可能錯誤：

1. 帳密驗證失敗
2. AI Hub API 無法連線
3. 來源網域不被允許

錯誤提示必須用人能理解的語言，不直接顯示後端 raw stack。

## 響應式規則

### Desktop

卡片寬度建議 480-640px。

### Mobile

卡片滿版但保留外邊距，按鈕高度不小於 44px。

## 可存取性要求

1. 表單欄位有清楚 label
2. 可完全以鍵盤完成登入
3. 錯誤訊息能被 screen reader 朗讀

## PM 驗收標準

1. AI Hub deep link 不會顯示入口頁。
2. 匿名模式可直接進建構頁。
3. 登入失敗會在頁內清楚提示。
4. 整頁不出現 Workflow 編排或工程設定資訊。
