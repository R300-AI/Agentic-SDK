# 鞋墊（足壓）知識庫 MVP 說明

本文件定義 `insole_pressure.json` 所依據的分級標準與推薦邏輯，作為知識庫維護與擴充的唯一依據來源。任何足弓指數門檻或足形分類調整，應先修改本文件，再同步更新 JSON 內對應欄位。

## 一、足弓指數（Arch Index, AI）分級標準

MVP 採用截斷式足印法（Cavanagh & Rodgers 簡化版）的比例分級，作為 AI agent 判斷依據。正式上線前建議與足壓量測設備廠商或合作醫療顧問覆核門檻數值。

| 分級 | AI 範圍 | 對應足形 |
|------|---------|----------|
| 高足弓 | AI ≤ 0.21 | 高弓足（Pes Cavus）／外旋不足 |
| 正常足弓 | 0.21 < AI ≤ 0.26 | 正常足弓（Neutral） |
| 低足弓／輕度扁平 | 0.26 < AI ≤ 0.32 | 低足弓、過度內旋傾向 |
| 扁平足 | AI > 0.32 | 扁平足（Pes Planus） |

> 註：`archsupport-pro`、`growstep-kids` 於 JSON 中以 `AI > 0.26` 概括「低足弓／輕度扁平」與「扁平足」兩級，因兩者產品建議方向相同（加強內側支撐）。若未來需依 0.32 門檻進一步細分產品，屆時再拆分條目。

## 二、足形分類（配合足壓分佈與主訴）

除足弓指數外，AI agent 亦須辨識以下足形／主訴標籤，兩者可並存（例如「扁平足」+「前足高壓」）：

- 正常足型（Neutral）
- 扁平足／過度內旋（Overpronation）
- 高弓足／外旋不足（Underpronation / Supination）
- 拇趾外翻（Hallux Valgus）
- 前足高壓／蹠骨痛（Metatarsalgia）
- 糖尿病足／感覺遲鈍高風險足（Diabetic / Insensate Foot）
- 兒童柔軟性扁平足（Pediatric Flexible Flatfoot，3-10 歲）
- 多重足型問題／標準品無法對應（客製化適用）

## 三、產品對照表

| 產品 id | 適用足弓指數 | 適用足形 | 備註 |
|---------|--------------|----------|------|
| archsupport-pro | AI > 0.26 | 扁平足、低足弓 | 高弓足禁用 |
| cloudcushion-higharch | AI ≤ 0.21 | 高弓足 | 扁平足禁用 |
| dailybalance-neutral | 0.21 < AI ≤ 0.26 | 正常足弓 | 無特定足型問題者 |
| metarelief-forefoot | 不限 | 前足高壓、蹠骨痛、輕度拇趾外翻 | 需另行確認前足壓力區 |
| promotion-sport | AI ≤ 0.26 | 正常足弓、高弓足 | 運動族群；扁平足不建議作主要矯正鞋墊 |
| sensocare-diabetic | 不限 | 糖尿病足、感覺遲鈍高風險足 | 有開放性傷口者需轉介醫療評估，不可直接下單 |
| growstep-kids | AI > 0.26，年齡 3-10 歲 | 兒童柔軟性扁平足 | 持續疼痛或僵硬性扁平足需轉介小兒骨科 |
| customfit-3d | 不限（需實測足壓數據） | 多重足型問題、標準品無法對應 | 下單前需完成足壓量測，非即買即用 |

## 四、AI agent 推薦決策邏輯（MVP）

建議順序（由上而下，符合條件即可納入候選，再依語意檢索排序呈現）：

1. **醫療風險優先攔截**：主訴包含開放性傷口、急性發炎、持續疼痛的僵硬性扁平足 → 停止產品推薦，導向「建議諮詢專業醫療評估」，不得直接導購。
2. **糖尿病／感覺遲鈍**：主訴包含糖尿病足、感覺遲鈍 → 優先推薦 `sensocare-diabetic`。
3. **前足局部主訴**：主訴包含前足痛、蹠骨痛、拇趾外翻且無其他嚴重足弓問題 → 推薦 `metarelief-forefoot`，可與足弓對應款式並列。
4. **依足弓指數比對**：依上述「產品對照表」的 AI 範圍篩出候選（`archsupport-pro` / `cloudcushion-higharch` / `dailybalance-neutral`）。
5. **運動情境加權**：使用情境為跑步、籃球等運動 → 在候選中加入或優先呈現 `promotion-sport`（僅限非扁平足）。
6. **兒童情境**：使用者年齡 3-10 歲 → 改用 `growstep-kids` 取代成人款。
7. **無法單一對應時**：使用者同時具備多重足型問題，或標準品皆不完全符合 → 推薦 `customfit-3d`，並說明需先完成足壓量測。

## 五、待確認項（MVP 已知缺口）

- AI 分級門檻（0.21 / 0.26 / 0.32）為文獻常見參考值，非本產品線實測校正值，需與足壓量測設備或醫療顧問確認是否採用相同量測方法與換算公式。
- 目前 8 款產品之售價、材質、圖片、購買連結為 MVP 示意內容，尚未對應實際 SKU 與電商後台資料，上線前需以真實商品資料覆核 `insole_pressure.json`。
- 兒童與糖尿病足類別涉及健康風險判斷，建議正式上線前由 PM／合規窗口確認免責聲明與轉介話術是否足夠。
