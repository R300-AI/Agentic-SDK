# LA NEW 鞋墊／鞋款知識庫 MVP 說明

本文件定義 `lanew_footwear.json` 所依據的分級標準、資料來源與推薦邏輯，作為知識庫維護與擴充的唯一依據來源。任何足弓指數門檻或楦頭足型分類調整，應先修改本文件，再同步更新 JSON 內對應欄位。

## 一、資料來源與擷取限制

JSON 內 7 筆商品皆對應 LA NEW 官網（www.lanew.com.tw）真實上架商品，資料擷取日期 2026-07-30。

| 欄位 | 來源 | 可信度 |
|------|------|--------|
| 商品名稱、售價、商品編號、網址 | 頁面內嵌 JSON-LD（`application/ld+json`） | 已驗證，可信 |
| 足弓指數分級（低／正常／高）、楦頭足型分類（寬楦避震型／正常楦控制型／正常楦穩定型／正常偏窄版型） | 業務方（需求提出者）指定之官方分類 | 視為權威輸入，未逐一與 LA NEW 內部量測數據交叉驗證 |
| 材質、支撐硬度、避震結構、楦頭實際寬度數據等技術規格 | **未擷取** | LA NEW 官網商品頁為前端動態渲染（91APP 平台），詳細規格以圖片呈現於頁面內，非文字內容，無法透過網頁擷取取得。JSON 各筆 `metadata.data_gap` 已逐筆標註 |

**上線前必須事項**：材質與技術規格需由業務方對照商品實體圖文頁面或供應商規格書人工補齊，不可依本 MVP 內容直接對外承諾功能細節。

## 二、足弓指數（Arch Index, AI）分級標準

沿用 `insole_pressure.md` 既有分級表，確保同一知識庫體系分級口徑一致：

| 分級 | AI 範圍 | 對應足形 |
|------|---------|----------|
| 高足弓 | AI ≤ 0.21 | 高弓足（Pes Cavus）／外旋不足 |
| 正常足弓 | 0.21 < AI ≤ 0.26 | 正常足弓（Neutral） |
| 低足弓／扁平傾向 | AI > 0.26 | 低足弓、過度內旋傾向 |

> LA NEW 商品僅提供「低／正常／高」三級官方分類，未細分「輕度扁平」與「扁平足」，故本知識庫將 AI > 0.26 一律對應「低」。

## 三、楦頭寬度／足型分類標準（鞋款專用，新定義）

鞋墊以足弓指數分級，鞋款則另以楦頭寬度與中足支撐需求分級，兩者為互補而非互斥的推薦維度：

| 分級 | 適用足型／需求 | 說明 |
|------|----------------|------|
| 寬楦避震型 | 腳掌偏寬、避震需求高 | 楦頭加寬，中底避震強化 |
| 正常楦控制型 | 標準楦寬、中足內旋控制需求較高 | 標準楦寬但支撐/控制結構較強 |
| 正常楦穩定型 | 標準楦寬、中足穩定需求中等 | 標準楦寬，穩定性優先於強力控制 |
| 正常偏窄版型 | 足型偏窄、腳背較低 | 楦頭較窄，適合經典正式鞋款版型 |

## 五、AI agent 推薦決策邏輯（MVP）

建議採兩段式推薦，鞋墊與鞋款分屬不同判斷維度，可分開推薦亦可組合呈現：

1. **足弓指數判斷（鞋墊）**：依使用者足弓指數（AI 量測值或自述足形）比對「二、足弓指數分級標準」，於 `lanew-insole-low` / `lanew-insole-normal` / `lanew-insole-high` 中擇一推薦。
2. **楦頭寬度／足型判斷（鞋款）**：
   - 使用者自述或量測腳掌偏寬、需要加強避震 → 推薦 `lanew-shoe-wide-cushion`。
   - 標準楦寬、有明顯內旋（足弓塌陷合併過度內旋）傾向 → 推薦 `lanew-shoe-normal-control`。
   - 標準楦寬、僅需一般中足穩定，無明顯內旋主訴 → 推薦 `lanew-shoe-normal-stability`。
   - 足型偏窄或需正式場合鞋款 → 推薦 `lanew-shoe-normal-narrow`。
3. **組合建議**：鞋墊與鞋款可並列呈現（例如足弓指數低 + 內旋傾向明顯者，可同時建議 `lanew-insole-low` 搭配 `lanew-shoe-normal-control`），但知識庫目前未內建鞋墊與鞋款的相容性規則（例如特定鞋款是否可放入客製鞋墊），呈現組合建議時應註明「鞋墊可否與該鞋款搭配使用」為未驗證項目。
4. **資料不足時**：若使用者主訴同時包含疼痛、傷口等醫療徵兆，本知識庫僅涵蓋一般零售鞋墊／鞋款商品，不含醫療分級判斷邏輯（可參考同目錄 `insole_pressure.json` 中的醫療風險攔截與轉介設計，如有需要應另行擴充）。

## 六、待確認項（MVP 已知缺口）

- 材質、支撐硬度、避震結構、楦頭實際寬度數據等技術規格未擷取（原始頁面為圖片呈現），需業務方或商品部門人工補齊後才可對外承諾功能細節。
- 足弓指數（低／正常／高）與楦頭足型分類為業務方提供之官方分類，未與 LA NEW 內部量測方法或門檻定義交叉驗證，正式上線前建議與商品線負責人確認分類依據。
- 「科技鞋墊-加強型」對應「足弓指數高」之設計邏輯未見於頁面文字說明，僅依業務方指定分類收錄，建議請商品部門確認命名與分級的對應關係是否為最終版本。
- 鞋墊與鞋款之間目前無相容性規則（例如客製鞋墊是否適用於特定楦型鞋款），如需支援組合推薦應另行補充。
- 售價為擷取當下（2026-07-30）之官網標示價格，可能隨促銷活動變動，正式串接應改為即時查詢電商後台或 API，而非寫死於知識庫檔案中。
