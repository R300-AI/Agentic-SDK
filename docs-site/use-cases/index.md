# Use Case

這一區不是 SDK API reference，而是把前面的 `Workflow`、`Module Family` 與引擎層組合成可落地的實施例，讓讀者更快判斷某個場景應該如何拆成 `Perceive`、`Plan`、`Retrieve`、`Action`、`Reflect`。

## 適合什麼時候看

- 當你已經理解五大家族，但還不知道如何落到真實業務。
- 當你要先決定資料準備、模組組合與流程循環，再回頭細查各模組參數。
- 當你要和產品、領域專家或客戶對齊一個可實作的 agent 方案。

## 收錄場景

- [LaNew 售鞋顧問](lanew-footwear-advisor.md)：以門市銷售與鞋款推薦為主，重點在商品知識檢索、需求理解與推薦說明。
- [BCI 射箭教練](bci-archery-coach.md)：以腦機介面輔助訓練為主，重點在多模態訊號判讀、訓練回饋與安全邊界。

## 閱讀方式

1. 先看你對應的產業場景頁，理解目標使用者、輸入資料與輸出責任。
2. 再對照 [Workflow Overview](../workflow-overview.md) 看流程循環是否合理。
3. 最後回到各功能頁，細化你要採用的模組與初始化參數。
